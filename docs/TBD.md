## 기능 (정할 것)

아직 방법을 정하지 않은 기능. 정하면 "확정 · 버전 대기" 로 옮긴다.

### TBD-26 생산 기록 (PRD 5장에서 옮김)

- **하려는 것**: 어떤 제품을 어떤 스풀(`S0000x`)로 몇 개 출력했는지 기록 → 스풀 구매가 기준 실제 원가
- **정할 것**: 출력 실패 보정을 여기서 할지 · v2 판매 장부(판매 시점 원가)와 어떻게 이을지 · 기록 방법(직접 입력 / QR 찍기, TBD-18 / 프린터 연동, TBD-27)

### TBD-27 프린터 연동 (PRD 5장에서 옮김)

- **하려는 것**: 프린터 제어 · 출력 기록 연동, 스풀 잔량 표시
- **정할 것**: 프린터 기종 · 연동 방법(LAN API 등). 설정 위치는 TBD-16 (`설정 › 프린터`)

### TBD-28 여러 사용자 (PRD 5장에서 옮김)

- **하려는 것**: 로그인, 사용자별 데이터
- **정할 것**: 필요한 시점 (지금은 혼자 · 같은 와이파이에서만 씀, SYS-02)

### TBD-34 스마트스토어 정산 엑셀 올리기 (v2 STORE-01 에서 옮김)

- **지금**: 커머스API 로 주문을 가져온다 (PRD 3.13). API 가 잘 돼서 v2 에서는 만들지 않았다
- **하려는 것**: API 가 안 될 때 예비 — 판매자센터에서 받은 정산 엑셀을 올리면 API 가져오기와 같은 미리보기로
- **정할 것**: 엑셀 형식 (실제 파일 샘플을 받아서) · 정산 엑셀에 상품주문번호가 있는지 (있어야 API 로 넣은 판매와 겹치지 않음)

### TBD-35 일반과세자 부가세 (v2 PL 에서 옮김)

- **지금**: 간이과세자 — 판매가(부가세 포함)를 그대로 매출, 낸 부가세는 지출 `세금` (PRD 3.12)
- **하려는 것**: 일반과세자가 되면 부가세는 손님에게 받아 대신 내는 돈이라 손익에서 빼기 (매출 · 매입 부가세)
- **정할 것**: 과세 유형이 바뀌는 시점 · 지출에 부가세를 따로 적을지 · 설정 › 손익 분류에 사업자 유형
