공통 부품 (v1.1.0)

모든 화면에서 함께 쓰는 부품. 버튼을 눌러 동작을 확인한다. 실제 화면에는 이 페이지가 없다.

확인 대화상자

TBD-09

브라우저 기본 확인 창(confirm) 대신 앱 대화상자. Esc · 취소 로 닫히고, 처음에는 취소 에 커서가 있어 Enter 로 실수 삭제하지 않는다.

  • 한 번 확인 — 그것만 지워지는 삭제
  • 2차 확인 — 다른 데이터도 지워지거나 바뀌는 삭제. 삭제 → 같은 창에서 빨간 정말 삭제 로 바뀌고 한 번 더 눌러야 실행
  • 삭제가 아닌 확인 — 스풀 거꾸로 이동처럼 되돌리는 동작. 파란 버튼

모달 크기 · 스크롤

TBD-01

창 머리(제목)와 아래(버튼 줄)는 그대로 두고 본문만 창 안에서 스크롤. 스크롤할 내용이 더 있으면 경계에 옅은 그림자.

  • 관리 창 (제품 관리 · 필라멘트 관리 · 부자재 관리 · 스풀 조정): 항목이 늘어나도 창 높이 고정 (최대 640px, 화면이 작으면 화면 높이까지)
  • 추가 · 수정 창: 지금처럼 내용만큼 크기. 화면보다 길어지면 본문만 스크롤
