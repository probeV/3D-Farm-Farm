# v1.2.0 계획 — 3D Farm Farm (쓰리디팜팜)

> 요구사항: [PRD.md](../PRD.md) · 화면: [screens.md](../screens.md) · 아이디어 보관함: [TBD.md](../TBD.md) · 다음: [v2.md](v2.md) (v2 브랜치)

이번 버전에서 할 일. **지출 장부** — 장비 · 재료 · 구독 등 쓴 돈을 기록하고 누적 투자금을 본다.
개발이 끝나면 [PRD.md](../PRD.md) · [screens.md](../screens.md) · [ERD.md](../ERD.md) 에 반영하고 이 파일은 지운다. 못 끝낸 항목은 다음 버전 계획이나 [TBD.md](../TBD.md) 로 옮긴다.

## 배경

- 아직 판매가 많지 않아 재료비 · 전기료보다 **초기 투자 비용**(필라멘트 건조기 · 노즐 같은 프린터 관리 용품, 라벨 프린터, AI 구독 등)이 대부분이다.
- 손익분기점은 "지금까지 들어간 돈"이 기준이라, 판매 기능보다 먼저 지출부터 기록해 둔다. 늦을수록 영수증 · 주문 내역을 찾기 어렵다.
- 판매 장부 · 손익계산서 · 스마트스토어 연동은 [v2](v2.md) 에서. 이번 버전은 **현금 기준**(실제로 나간 돈)만 다룬다.

## 기능 — 지출 장부 `EXP`

| ID | 기능 | 내용 |
|---|---|---|
| EXP-01 | 지출 목록 | 날짜 · 항목명 · 분류 · 구매처 · 금액 · 메모. 기본 최근 날짜순, 열 제목으로 정렬(TBD-05). 반복 지출에서 넣은 줄은 `↻ 반복`, 주문 링크가 있으면 `주문` 버튼(새 탭) |
| EXP-02 | 지출 추가 / 수정 / 삭제 | 날짜(기본 오늘, 오늘 이후 불가), 항목명, 분류(버튼 7개 + 고른 분류가 v2 에서 어떻게 쓰이는지 한 줄), 금액(원), 구매처(선택), 주문 링크(선택, 주소 형식 검사), 메모(선택). 복제(값 복사, 날짜는 오늘). 삭제는 확인 한 번 |
| EXP-03 | 분류 | `투자(장비)` · `필라멘트` · `부자재` · `소모품 · 유지` · `구독 · 운영` · `판매비` · `기타` |
| EXP-04 | 반복 지출 (구독) | 월마다 같은 금액이 나가는 것(AI 구독 · 플랫폼 월정액). `반복 지출 관리` 창에서 이름 · 금액 · 분류 · 결제일(매달 N일) · 시작 달을 등록. 저절로 넣지 않고, 결제일이 지났는데 이번 달에 안 넣은 것이 있으면 화면에 알림 줄 → `확인하고 넣기` 에서 줄마다 체크 · 이번 달 금액 고쳐서 넣는다 (날짜 = 결제일, 말일보다 크면 말일). 그만 낼 때는 삭제(이미 넣은 지출은 남음), 다시 내면 새로 등록 — 해지 달은 두지 않는다 |
| EXP-05 | 요약 | 카드 3개: **누적 투자금**(`투자(장비)` 합계) · 누적 지출(전체 기간) · 이번 달 지출. 그 아래 분류별 합계 막대 (기간 필터를 따름, 누르면 그 분류만) |
| EXP-06 | 검색 · 필터 | 기간(이번 달 / 올해 / 전체 / 직접 지정) · 분류 · 항목명 · 구매처 검색 |
| EXP-07 | CSV 내보내기 | 보이는 목록을 엑셀용 CSV(UTF-8 BOM)로 (PRD-10 과 같은 방식) |
| EXP-08 | 메뉴 | 사이드바에 `지출` (PRD SYS-05) |

### 분류 기준 (EXP-03)

| 분류 | 예 | v2 손익 기준에서 (현금 기준은 모두 산 날 지출) |
|---|---|---|
| 투자(장비) | 프린터 · 필라멘트 건조기 · 라벨 프린터 | 넣지 않음. 투자 회수율로 따로 (감가상각 없음) |
| 필라멘트 | 필라멘트 스풀 | 넣지 않음. 사용 시작한 스풀 구매가로 대신 |
| 부자재 | 자석 · 박스 · OPP 봉투 | 재료비 (산 날) |
| 소모품 · 유지 | 노즐 · 베드 시트 · 윤활유 | 운영비 |
| 구독 · 운영 | AI 구독 · 플랫폼 월정액 · 전기요금 | 운영비 |
| 판매비 | 택배비 · 포장 외 발송비 · 광고비 | 운영비 |
| 기타 | 위에 안 맞는 것 | 운영비 |

- 지금 정해 두는 이유: v2 손익이 이 분류를 그대로 쓴다. 장비 · 필라멘트처럼 손익 기준에서 다르게 다루는 것을 처음부터 나눠 두어야 나중에 다시 분류하지 않는다

## 개선 — 제품 원가 세부 창

| 대상 | 지금 | 바꿀 것 |
|---|---|---|
| 사용 필라멘트 · 사용 부자재 추가 (PRD-05 · PRD-06) | 따로 있는 추가 버튼 — 디자인이 어색함 | 목록 맨 밑에 `+` 항목 하나를 두고, 누르면 그 자리에 새 줄 추가 (`필라멘트 관리` 창 목록과 같은 방식) |

## 정함

- **분류**: 위 7개 고정 (코드로 v2 계산과 연결, 사용자가 추가 · 수정하지 않음)
- **반복 지출 넣는 방식**: 자동 생성 없이 알림 줄 + `확인하고 넣기` (EXP-04). 결제일이 지난 것만 알림
- **스풀 · 부자재 구매와 연결**: 하지 않고 따로 입력 (지출은 주문 단위 · 배송비 포함, 스풀은 한 통 단위라 맞지 않음). 필요해지면 나중에
- **누적 투자금 범위**: `투자(장비)` 만 (v2 투자 회수율과 같은 기준)
- **영수증 · 첨부**: 파일 첨부 없음. 주문 링크(선택)만
- **할부 · 여러 개 묶음 구매**: 결제 금액 그대로 한 줄 (할부는 실제로 빠져나간 날 기준)
- **설정 위치**: 지금은 지출에 설정이 없다. 필요해지면 [TBD-16](../TBD.md)(설정 한곳에 모으기)과 함께
