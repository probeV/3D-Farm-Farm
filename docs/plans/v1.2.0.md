# v1.2.0 계획 — 3D Farm Farm (쓰리디팜팜)

> 요구사항: [PRD.md](../PRD.md) · 화면: [screens.md](../screens.md) · 아이디어 보관함: [TBD.md](../TBD.md) · 다음: [v2.md](v2.md) (v2 브랜치)

이번 버전에서 할 일. **지출 장부** — 장비 · 재료 · 구독 등 쓴 돈을 기록하고 누적 투자금을 본다.
개발이 끝나면 [PRD.md](../PRD.md) · [screens.md](../screens.md) · [ERD.md](../ERD.md) 에 반영하고 이 파일은 지운다. 못 끝낸 항목은 다음 버전 계획이나 [TBD.md](../TBD.md) 로 옮긴다.

## 배경

- 아직 판매가 많지 않아 재료비 · 전기료보다 **초기 투자 비용**(필라멘트 건조기 · 노즐 같은 프린터 관리 용품, 라벨 프린터, AI 구독 등)이 대부분이다.
- 손익분기점은 "지금까지 들어간 돈"이 기준이라, 판매 기능보다 먼저 지출부터 기록해 둔다. 늦을수록 영수증 · 주문 내역을 찾기 어렵다.
- 판매 장부 · 손익계산서 · 스마트스토어 연동은 [v2](v2.md) 에서. 이번 버전은 **현금 기준**(실제로 나간 돈)만 다룬다.

## 기능 — 지출 장부 `EXP`

| ID | 기능 | 내용 |
|---|---|---|
| EXP-01 | 지출 목록 | 날짜 · 항목명 · 분류 · 금액 · 구매처 · 메모. 기본 최근 날짜순 |
| EXP-02 | 지출 추가 / 수정 / 삭제 | 날짜(기본 오늘), 항목명, 분류, 금액(원), 구매처(선택), 메모(선택). 복제(값 복사, 날짜는 오늘) |
| EXP-03 | 분류 | `투자(장비)` · `재료` · `소모품 · 유지` · `구독 · 운영` · `판매비` · `기타` |
| EXP-04 | 반복 지출 (구독) | 월마다 같은 금액이 나가는 것(AI 구독 · 플랫폼 월정액). 이름 · 금액 · 분류 · 결제일 · 시작일 · 해지일(선택)을 등록해 두면 매달 지출로 들어간다 |
| EXP-05 | 요약 | **누적 투자금**(`투자(장비)` 합계) · 누적 지출 · 이번 달 지출 · 분류별 합계 |
| EXP-06 | 검색 · 필터 | 기간(이번 달 / 올해 / 전체 / 직접 지정) · 분류 · 항목명 · 구매처 검색 |
| EXP-07 | CSV 내보내기 | 보이는 목록을 엑셀용 CSV(UTF-8 BOM)로 (PRD-10 과 같은 방식) |
| EXP-08 | 메뉴 | 사이드바에 `지출` (PRD SYS-05) |

### 분류 기준 (EXP-03)

| 분류 | 예 | v2 손익계산서에서 |
|---|---|---|
| 투자(장비) | 프린터 · 필라멘트 건조기 · 라벨 프린터 | 투자금. 손익에는 감가상각으로 나눠 반영 |
| 재료 | 필라멘트 · 부자재 | 매출원가 쪽 (재고) |
| 소모품 · 유지 | 노즐 · 베드 시트 · 윤활유 | 판매비와 관리비 |
| 구독 · 운영 | AI 구독 · 플랫폼 월정액 | 판매비와 관리비 |
| 판매비 | 택배비 · 포장 외 발송비 · 광고비 | 판매비와 관리비 |
| 기타 | 위에 안 맞는 것 | 판매비와 관리비 |

- 지금 정해 두는 이유: v2 손익계산서가 이 분류를 그대로 쓴다. 투자(자산)와 비용을 처음부터 나눠 두어야 나중에 다시 분류하지 않는다

## 정할 것

- **분류 고정 / 직접 관리**: 위 6개 고정(코드로 v2 계산과 연결) / 제품 카테고리처럼 직접 추가하되 각 분류가 v2 의 어느 항목인지 고르기
- **반복 지출 넣는 방식**: 결제일이 지나면 자동으로 지출 줄 생성 / 화면에 "이번 달 구독 N건 추가" 버튼으로 확인 후 생성 (금액이 바뀐 달을 고치기 쉬움)
- **스풀 · 부자재 구매와 연결**: 스풀 재고 추가(INV-02)에서 이미 구매가를 입력한다. 지출에 자동으로 넣을지 / 따로 입력할지 (두 번 입력 vs 자동 연결의 복잡도)
- **누적 투자금 범위**: `투자(장비)` 만 / 모든 지출 (손익분기점 기준을 무엇으로 볼지 — v2 회수율과 같은 기준)
- **영수증 · 첨부**: 이미지 · PDF 첨부를 둘지 (회사 이미지 업로드 FIL-01a 와 같은 방식) / 링크(주문 내역 주소)만
- **할부 · 여러 개 묶음 구매**: 한 줄로 / 나눠서
- **설정 위치**: 지출에 설정이 필요해지면 [TBD-16](../TBD.md)(설정 한곳에 모으기, v1.1.0 브랜치 TBD.md)과 함께
