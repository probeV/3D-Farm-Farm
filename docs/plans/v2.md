## 돈을 보는 두 관점

같은 지출 · 판매 기록을 두 가지로 계산한다. 필라멘트를 살 때(지출)와 팔 때(제품 원가) 두 번 빠지지 않게 하기 위함.

| 관점 | 필라멘트 20,000원 구매 · 원가 3,000원 제품 1개 판매 | 쓰는 곳 |
|---|---|---|
| **현금 기준** | 20,000원 나감 | 통장에서 실제로 나간 돈 · 들어온 돈. 투자금 회수 · 손익분기점 |
| **손익 기준** | 3,000원 (매출원가) | 판 물건에 실제로 쓰인 재료값. 나머지 17,000원은 아직 안 쓴 재고. 월별 손익 · 손익계산서 |

- 손익 기준에서 `재료` 지출은 손익에 넣지 않고, 판매 기록의 **판매 시점 원가**를 매출원가로 쓴다
- 실패 출력 · 테스트 출력 · 자투리는 제품 원가에 안 잡힌다 → 필요하면 `재료 지출 − 매출원가 합계` 를 재료 손실로 보여 준다 (정할 것)

## 기능

### 판매 장부 — `SALE`

| ID | 기능 | 내용 |
|---|---|---|
| SALE-01 | 판매 목록 | 날짜 · 판매처(스마트스토어 · 직접 판매 등) · 제품 · 수량 · 판매가 · 수수료 · 배송비 · 정산 금액 |
| SALE-02 | 판매 추가 / 수정 / 삭제 | 제품은 등록된 제품에서 고른다. 판매가 · 수수료는 제품 · 제품 원가 설정(SET-06 · 07)에서 기본값, 고칠 수 있음 |
| SALE-03 | 판매 시점 원가 | 저장할 때 그 제품의 원가를 판매 기록에 **복사**해 둔다. 나중에 필라멘트 · 부자재 가격이 바뀌어도 지난 판매의 매출원가는 그대로 |
| SALE-04 | 한 주문에 여러 제품 | 주문 하나에 제품 여러 줄 (배송비 · 포장비는 주문 단위) |

### 손익 — `PL`

| ID | 기능 | 내용 |
|---|---|---|
| PL-01 | 손익계산서 (월 · 연) | 아래 계산 순서. 기간 선택 |
| PL-02 | 투자 회수 | 누적 투자금 · 누적 순이익 · **회수율** (누적 순이익 ÷ 누적 투자금) |
| PL-03 | 손익분기점 | 개당 평균 이익 기준 "앞으로 N개 더 팔면 회수" |
| PL-04 | 월별 그래프 | 월별 매출 · 비용 · 이익 막대 |
| PL-05 | 감가상각 | `투자(장비)` 지출을 사용 기간(예: 3년)으로 나눠 매달 비용으로. 제품 원가 설정에서 뺀 프린터 감가상각을 여기서 다룬다 |
| PL-06 | 세금 | 종합소득세 등 낸 세금을 지출로 기록해 순이익에서 뺀다. 지출 분류(EXP-03)에 `세금` 추가 |

#### 계산 순서

```
매출액                 판매 장부의 판매가 합계
− 매출원가             판매 시점 원가 합계 (SALE-03)
= 매출총이익
− 판매비와 관리비       수수료 · 택배비 · 광고비 · 구독 · 소모품 · 감가상각(PL-05)
= 영업이익
± 영업외 손익           이자 수입 · 이자 비용 등
− 세금                 종합소득세 등
= 당기순이익
```

- **감가상각은 영업외가 아니라 판매비와 관리비** (영업 비용)
- **부가세는 비용이 아니다**: 손님에게 받아 대신 내는 돈이라 손익에서 뺀다. 간이과세자면 처리가 달라 사업자 유형에 맞춘다

### 스마트스토어 연동 — `STORE`

| ID | 기능 | 내용 |
|---|---|---|
| STORE-01 | 정산 엑셀 올리기 | 판매자센터에서 받은 주문 · 정산 엑셀을 올리면 판매 장부로 (판매가 · 수수료 · 정산 금액) |
| STORE-02 | 상품 연결 | 스토어 상품(옵션)과 이 앱의 제품을 한 번 짝지어 두고, 다음부터 자동으로 |
| STORE-03 | 커머스 API | 주문 · 정산 조회 API 로 자동 가져오기. 엑셀 올리기가 자리 잡은 뒤에 (API 사용 신청 · 인증 필요) |

- 스마트스토어는 매출 · 수수료까지만 준다. 원가 · 다른 비용 · 손익은 이 앱에서 계산한다
