# Print Farm Farm (프린트팜팜)

3D 프린팅 원가 계산 · 필라멘트 재고 관리 웹앱

> 🚧 Django 로 개발 중입니다.

## 주요 기능 (예정)
- **제품 원가 계산**: 필라멘트비, 전기료, 프린터 감가상각, 실패 보정, 부자재비, 스마트스토어 수수료를 반영한 순이익·마진율
- **필라멘트 재고**: 회사·재질별 필라멘트, 색상별 스풀 재고 (미개봉 / 개봉 / 사용완료), 스풀별 구매가
- **변경 이력과 되돌리기**: 스풀 상태 변경을 이력으로 남기고 동작 단위로 되돌리기
- **부자재 관리**: 자석, 나사, 포장재 등 묶음 구매가 → 개당 단가

## 기술 스택
- Python, Django
- SQLite (로컬)

## 개발 규칙

### 브랜치 (GitHub Flow)
- `main`: 항상 동작하는 상태만 유지
- 작업 브랜치: `종류/작업-내용` 형식으로 만들고, 완료되면 PR 로 `main` 에 병합
  - 예: `feat/django-setup`, `feat/filament-inventory`, `fix/undo-order`

### 커밋 메시지 (Conventional Commits)
`종류: 한 줄 요약`

| 종류 | 용도 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변화 없는 구조 개선 |
| `docs` | 문서 |
| `test` | 테스트 |
| `chore` | 설정, 빌드, 기타 |

예: `feat: 필라멘트 스풀 재고 모델 추가`
